Cloudflare → Rules → Transform Rules → Modify response header
================================================================
GitHub Pages + Cloudflare proxy: _headers dosyası kendiliğinden uygulanmaz.
Aşağıdaki başlıkları bir Response header transform rule ile ekleyin.

Rule name: Rutin Temizlik security headers
If: Hostname equals www.rutintemizlikantalya.com.tr
     OR Hostname equals rutintemizlikantalya.com.tr

Then — Set static (her satır ayrı header):

1) Content-Security-Policy
default-src 'self'; base-uri 'self'; object-src 'none'; frame-ancestors 'none'; form-action 'self'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; media-src 'self'; connect-src 'self'; upgrade-insecure-requests

2) Strict-Transport-Security
max-age=31536000; includeSubDomains

3) X-Frame-Options
DENY

4) X-Content-Type-Options
nosniff

5) Referrer-Policy
strict-origin-when-cross-origin

6) Permissions-Policy
accelerometer=(), camera=(), geolocation=(), gyroscope=(), microphone=(), payment=(), usb=()

7) Cross-Origin-Opener-Policy
same-origin

8) Cross-Origin-Resource-Policy
same-origin

Doğrulama (PowerShell / curl):
curl.exe -sI https://www.rutintemizlikantalya.com.tr/ | findstr /I "content-security strict-transport x-frame"

Beklenen: Content-Security-Policy ve Strict-Transport-Security satırları görünür.
